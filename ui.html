配置填写示例

将对应 JSON 复制到配置编辑器的同名输入框，再将示例凭据索引替换为实际值。以下三个示例可以配合使用。

auth_indexes：仅限制指定的凭据。留空或填写 [] 会限制所有供应商凭据。

["codex-index-a", "codex-index-b"]

account_groups：将同一真实账户的多份凭据合并计数。留空或填写 {} 不合并。

{
  "codex-index-a": "codex-shared",
  "codex-index-b": "codex-shared"
}

account_limits：为上述分组设置每分钟 5 次、并发 2。未填写的字段继承全局阈值；留空或填写 {} 使用全局配置。

{
  "codex-shared": {
    "requests_per_minute": 5,
    "max_concurrency": 2
  }
}
